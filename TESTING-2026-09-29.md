## 1. Loading and replaying a game

- [ ] Find game by username → open a game. You should see **Replay as [White] [Black]** with "you were X", and nothing should move yet.
- [ ] Pick your side. The board should flip to your side, stay paused, and the status should say it's your move or tell you to press ▶.
- [ ] Play your actual game move. The opponent's reply should follow on its own, about 0.7 s later.
- [ ] Press ◀ several times, then ▶. It should step through without the opponent's move bouncing forward on its own.
- [ ] Play a **different** move than you played. It should snap back, and you should see an arrow to your real move plus **[Play X vs bot] [Take it back]**.
- [ ] **Take it back** should clear it and continue the replay.
- [ ] **Exit replay** should drop to plain review, where you can move both sides, and show the side picker again.

## 2. Branching to the bot

- [ ] Deviate, then **Play X vs bot**. The chat note should name the bot level and the rating it matched ("matched to …'s 836 rating").
- [ ] The moves list should include the original game's moves before your new move, and ◀/⏮ should step back into them.
- [ ] Takeback should undo only moves after the branch point, then turn grey.
- [ ] **Back to the game** should put you back in the replay at the move where you branched, paused.
- [ ] (Optional, runs a full engine pass) Finish a bot game → **Review this game**. It should analyse the whole game from move 1.

## 3. Per-move cards (costs money on big swings)

- [ ] Step through a game with the arrow keys. You should get one collapsible card per move (Played, Best, ▶ Best line), with older cards collapsing.
- [ ] **▶ Best line** should play from the position _before_ the move.
- [ ] Stay 2+ seconds on a move marked inaccuracy or mistake. A "⚠ Big moment" explanation should appear. **Check it's about the right move and matches the numbers on the card.**
- [ ] Scrub quickly past a mistake. No Big-moment call should fire.
- [ ] **Why?** on a card that already got a Big-moment explanation should come back instantly (reused, no new charge).

## 4. Engine lines

- [ ] The eval bar and engine lines should be on in review, in replays, and in branched bot games.
- [ ] Uncheck Engine lines, reload, and check it stays off. Then turn it back on.

## 5. Learn openings: existing lessons (free)

- [ ] Learn openings → search "najdorf" → it should show "✓ built" → Start lesson. You should see an overview card (summary, key ideas, pawn breaks, wait for, mistakes).
- [ ] **Learn the main line** → step with →. Each move should get a card; at 5...a6 you should see **Their tries**: Be3 / Bg5 / Be2.
- [ ] Click a try button. The board should follow that branch.
- [ ] Play a move that isn't in the lesson. It should say "not in this lesson", let you analyse freely, and ◀ should take you back.
- [ ] **Drill**:
  - [ ] The opponent moves first (you're Black).
  - [ ] A wrong move gets a circle on the piece and "try again".
  - [ ] A second wrong move gets the arrow plus the note.
  - [ ] At the end of a line: "Line complete", with the mastered count.
- [ ] Drill the same line twice with no mistakes. It should show "mastered", and the next drill should steer to a different line.
- [ ] **Read the notes like a coach would.** Anything chess-wrong ("attacks X" when it doesn't, a wrong plan) goes to Claude, with the move. The notes were spot-checked, not proved.
- [ ] Same for the Dragon, including the 9.Bc4 Bd7 10.h4 **h5** line.
